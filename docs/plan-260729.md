下面方案沿用DT4LM的模块划分、词级修改成本及评估指标；首轮选择Kuleshov配置，是因为论文实验中它的查询成本明显低于LEAP和FastGA。 语义约束默认采用`FacebookAI/roberta-large-mnli`，其官方模型卡说明该模型是基于MNLI微调的英文RoBERTa-large，可直接通过Transformers加载。([Hugging Face][1])

# DT4LM的改进方向

## 1. 研究目标

分别改进DT4LM中的两个模块：

1. **语义保持方法 SemDT**
   - 不改变DT4LM的目标函数和搜索方法。
   - 在原有约束后增加NLI过滤。
   - 目标是减少语义已经变化的伪差分输入。

2. **字典序目标方法 LexiDT**
   - 不改变DT4LM的文本变换和语义约束。
   - 将原有分段线性组合目标替换为阈值字典序目标。
   - 目标是让搜索过程直接对应“旧模型正确、新模型错误、修改尽量少”。

两个方法必须先独立实验，最后只做一个可选组合实验。

# 2. 统一的基础配置

## 2.1 首轮使用的基础Recipe

首轮实验只使用论文中的Kuleshov配置，降低查询成本：

- 修改方法：基于词嵌入近邻的单词替换；
- 原有约束：
  - 语义相似度约束；
  - 停用词不可修改；
  - 同一位置不可重复修改；
- 搜索方法：贪心搜索；
- 查询预算、候选数量等参数：沿用DT4LM官方实现。

首轮不使用LEAP和FastGA。只有方法有效后，再扩展到另外两种Recipe。

## 2.2 差分输入成功条件

沿用DT4LM定义。对于标签为 \(y\) 的原始输入 \(x\)，候选 \(x'\) 满足：

\[
\operatorname{pred}_{old}(x')=y,
\qquad
\operatorname{pred}_{new}(x')\neq y.
\]

## 2.3 修改成本

直接沿用DT4LM的AMR定义，不引入新的编辑成本：

\[
c(x,x')
=
\frac{N_{\mathrm{modified}}(x,x')}
     {N_{\mathrm{words}}(x)}.
\]

其中：

- \(N_{\mathrm{modified}}\)：根据变换过程记录的被替换单词数；
- \(N_{\mathrm{words}}\)：原始输入的单词数；
- 不使用Transformer子词数量；
- 不使用Levenshtein距离；
- 当前Recipe只有单词替换，不涉及插入和删除。

对于RTE和MRPC的句子对：

\[
c(x,x')
=
\frac{N_{\mathrm{modified}}(s_1,s'_1)
      +N_{\mathrm{modified}}(s_2,s'_2)}
     {N_{\mathrm{words}}(s_1)+N_{\mathrm{words}}(s_2)}.
\]

若只修改一个句子，另一个句子的修改数记为0。

# 3. 方法一：SemDT——NLI语义约束

## 3.1 保持不变的部分

SemDT完全沿用DT4LM的：

- Kuleshov词级修改方法；
- 原有停用词、重复修改和相似度约束；
- 原论文动态目标函数；
- 贪心搜索；
- 差分输入成功条件；
- 修改成本和查询预算。

SemDT只增加一个新的语义过滤模块。

## 3.2 NLI模型

默认模型：

```text
FacebookAI/roberta-large-mnli
```

实现时从以下字段读取标签映射：

```python
model.config.id2label
```

不要硬编码entailment、neutral和contradiction的类别编号。

该模型只负责语义过滤，不参与新旧模型的预测，也不进行微调。

## 3.3 双向NLI分数

对原句 (x) 和候选句 (x')，分别执行：

[
x\Rightarrow x',
\qquad
x'\Rightarrow x.
]

得到：

[
p^E_{\rightarrow}
= 
P(\mathrm{entailment}\mid x,x'),
]

[
p^E_{\leftarrow}
= 
P(\mathrm{entailment}\mid x',x),
]

以及两个方向的contradiction概率：

[
p^C_{\rightarrow},\qquad p^C_{\leftarrow}.
]

定义：

[
S_E(x,x)
= 
\min(p^E_{\rightarrow},p^E_{\leftarrow}),
]

[
S_C(x,x)
= 
\max(p^C_{\rightarrow},p^C_{\leftarrow}).
]

使用最小entailment和最大contradiction，避免只有一个方向语义成立。

## 3.4 句子对任务

对于：

[
x=(s_1,s_2),\qquad x'=(s'_1,s'_2),
]

只检查实际发生修改的句子。

如果两个句子均被修改，则：

[
S_E(x,x)
= 
\min\left(
S_E(s_1,s'_1),
S_E(s_2,s'_2)
\right),
]

[
S_C(x,x)
= 
\max\left(
S_C(s_1,s'_1),
S_C(s_2,s'_2)
\right).
]

不将两个完整句子对拼接后直接计算NLI，以免原任务中的句间关系干扰改写等价性判断。

## 3.5 阈值

提供两种设置阈值的方式：（1）人工指定，（2）通过搜索自动确定。

### 人工指定

直接在配置文件中设置相关阈值，默认：

[
S_E\ge 0.90
\quad\land\quad
S_C\le 0.05.
]

为接受。

### 通过搜索自动确定

1. 在训练集上挑选若干样本，运行原始 DT4LM，收集通过原有约束的候选对。
2. 对候选对计算 S_E 和 S_C。
3. 调用 LLM，标注每个候选对的语义保持标签。
4. 根据 LLM 标签搜索最佳阈值。

#### LLM
建议使用强指令 LLM 来判断修改后的完整输入是否保留当前任务语义，并继续对应原始标签。输出必须是二值标签，解析失败则丢弃样本。
将尝试调用本地 HF 模型和调用API（先仅实现 openai 接口）两种方案，因此需要模块化设计。必须设置 temperature = 0。

建议操作：

* 使用FP16或BF16；
* 双向句对合并为同一批次；
* 按显存设置batch size；
* 模型参数冻结。

结果中保存：
1. 标注后样本，包括：
   * 原始输入；
   * 生成候选；
   * S_E；
   * S_C；
   * LLM 标签。
2. LLM 配置，包括：
   * 模型完整名称和版本；
   * 调用日期；
   * prompt；
   * 输出解析失败率。

#### 搜索
语义约束中，错误接受一个语义已经变化的输入，比错误拒绝一个有效输入更严重。
所以阈值搜索建议以 recall 为主目标，以 precision 为约束。
首版采用简单网格搜索即可。

## 3.6 SemDT评估

### 自动指标

沿用DT4LM：

* GSR；
* AMR；
* QPS；
* BERTScore；
* BLEU；
* METEOR；
* ROUGE。

### 人工评估

建议抽取100组成功样本，每组包含：

* 原始输入；
* DT4LM生成输入；
* SemDT生成输入。

人工判断 DT4LM 与 SemDT 保持标签与语义的情况，作为首轮可行性验证。

### 成功标准

SemDT值得继续扩展，需要满足：

1. 人工语义保持率至少提高5个百分点；
2. 估计的 ValidGSR 不低于Base；
3. QPS增幅不超过30%；
4. 报告运行时NLI额外耗时和显存开销。

# 4. 方法二：LexiDT——阈值字典序目标

## 4.1 保持不变的部分

LexiDT完全沿用DT4LM的：

* Kuleshov词级修改方式；
* 原有语义相似度约束；
* 停用词和重复修改约束；
* 贪心搜索流程；
* 查询预算；
* 差分输入定义；
* 修改成本 (c(x,x'))。

LexiDT只替换目标函数和候选排序方式。

LexiDT首轮不使用SemDT的NLI或LLM约束，以保证两个方法独立。

## 4.2 分类Margin

优先从模型输出logits计算margin。

旧模型正确margin：

[
m_{\mathrm{old}}(x')
= 
z_{\mathrm{old},y}(x')
-
\max_{k\ne y}z_{\mathrm{old},k}(x').
]

当：

[
m_{\mathrm{old}}(x')>0
]

时，旧模型预测正确。

新模型错误margin：

[
m_{\mathrm{new}}(x')
= 
z_{\mathrm{new},y}(x')
-
\max_{k\ne y}z_{\mathrm{new},k}(x').
]

当：

[
m_{\mathrm{new}}(x')>0
]

时，新模型预测错误。

如果接口只返回概率，则使用log概率：

[
m_{\mathrm{old}}
= 
\log(p_{\mathrm{old},y}+\epsilon)
-
\log\left(
\max_{k\ne y}p_{\mathrm{old},k}+\epsilon
\right),
]

[
m_{\mathrm{new}}
= 
\log(p_{\mathrm{new},y}+\epsilon)
-
\log\left(
\max_{k\ne y}p_{\mathrm{new},k}+\epsilon
\right),
]

其中：

[
\epsilon=10^{-12}.
]

## 4.3 阈值截断

首轮不设置额外安全margin：

[
\kappa_{\mathrm{old}}=0,
\qquad
\kappa_{\mathrm{new}}=0.
]

定义：

[
g_{\mathrm{old}}(x')
= 
\min(m_{\mathrm{old}}(x'),0),
]

[
g_{\mathrm{new}}(x')
= 
\min(m_{\mathrm{new}}(x'),0).
]

解释：

* 旧模型错误时，(g_{\mathrm{old}}<0)，越接近0越好；
* 旧模型正确后，(g_{\mathrm{old}}=0)，不再奖励继续提高旧模型置信度；
* 新模型正确时，(g_{\mathrm{new}}<0)，越接近0越接近回归；
* 新模型错误后，(g_{\mathrm{new}}=0)，不再奖励让新模型更加错误。

## 4.4 字典序目标

候选输入按照下列元组从大到小排序：

[
G_{\mathrm{LexiDT}}(x')
= 
\left(
g_{\mathrm{old}}(x'),
g_{\mathrm{new}}(x'),
-c(x,x')
\right).
]

比较顺序为：

1. 首先保证旧模型正确；
2. 在旧模型正确的候选中，让新模型跨越错误边界；
3. 两个条件均满足后，选择修改成本最低的输入。

## 4.5 候选比较器

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class LexiScore:
    old_score: float
    new_score: float
    neg_cost: float

    def as_tuple(self) -> tuple[float, float, float]:
        return self.old_score, self.new_score, self.neg_cost


def build_lexi_score(
    old_margin: float,
    new_margin: float,
    modification_cost: float,
) -> LexiScore:
    if not 0.0 <= modification_cost <= 1.0:
        raise ValueError("modification_cost must be in [0, 1].")

    return LexiScore(
        old_score=min(old_margin, 0.0),
        new_score=min(new_margin, 0.0),
        neg_cost=-modification_cost,
    )


def select_best(candidates):
    if not candidates:
        raise ValueError("Candidate list is empty.")

    return max(
        candidates,
        key=lambda item: item.lexi_score.as_tuple(),
    )
```

若两个候选的元组完全相同，沿用原DT4LM实现中的稳定顺序；若原实现没有稳定顺序，则按候选生成顺序选择，不额外增加随机因素。

## 4.6 搜索与终止

每轮流程：

```text
1. 生成候选；
2. 应用DT4LM原有约束；
3. 查询新旧模型；
4. 为每个候选计算LexiDT元组；
5. 按字典序选出最优候选；
6. 进入下一轮修改。
```

如果当前候选集合中存在多个成功差分输入：

[
g_{\mathrm{old}}=0,
\qquad
g_{\mathrm{new}}=0,
]

则从这些成功输入中选择：

[
\arg\min_{x'}c(x,x')
]

并立即终止当前原始样本的搜索。

这沿用DT4LM“找到成功输入后转向下一原始样本”的原则，只是在同一轮多个成功候选中明确选择修改成本最低者。

## 4.7 LexiDT评估

对比：

1. DT4LM-static；
2. DT4LM-dynamic；
3. LexiDT。

保持以下内容相同：

* 原始样本；
* 候选生成方式；
* 约束；
* 查询预算；
* 搜索方法。

指标：

* GSR；
* AMR；
* QPS；
* Success@100；
* Success@500；
* Success@1000。

其中：

[
\mathrm{Success@B}
= 
\frac{
#\text{在不超过B次查询时成功的样本}
}{
#\text{测试样本}
}.
]

### 成功标准

LexiDT值得继续扩展，需要满足下列任一条件：

1. GSR提高至少2个百分点，且AMR、QPS没有明显恶化；
2. GSR基本相同，但QPS下降至少10%；
3. GSR基本相同，但AMR下降至少10%；

# 5. 最小实验计划

## 5.1 实验范围

首轮仅使用：

* 数据集：SST-2、RTE；
* 模型对：ALBERT；
* Recipe：Kuleshov；
* 每个数据集随机抽取500个输入；

但注意：
1. 最终评估用的模型包含：Encoder-only（ALBERT 或 DeBERTa）、Decoder-only（Qwen 或 LLaMa）、Encoder-Decoder（T5），所以要封装好接口。
2. Encoder-only 与 Encoder-Decoder 模型可能要先根据任务微调，所以工作流上是先微调模型，然后作为每组实验的公共模型使用。DT4LM/experiments/finetune/ 中有基于 textattack 的微调示例，我们效仿即可。

## 5.2 实验组

| 编号       | 语义模块        | 目标模块      | 用途     |
| -------- | ----------- | --------- | ------ |
| Base     | DT4LM原约束    | DT4LM动态目标 | 基线     |
| SemDT    | NLI | DT4LM动态目标 | 验证语义方向 |
| LexiDT   | DT4LM原约束    | 字典序目标     | 验证目标方向 |
| Combined | NLI | 字典序目标     | 仅检查兼容性 |

首版只回答两个问题：

1. **通过NLI，能否减少语义无效的差分输入？**
2. **通过阈值字典序排序，能否比经验性线性组合更有效地找到回归输入？**
