# AE-PBS：自适应 ε 约束的 Pareto Beam 差分搜索改造计划

## 1. 方案定位

本方案改进 DT4LM 的**目标函数与搜索模块**，不改变文本修改方式和语义约束。

DT4LM 当前将旧模型置信度和新模型置信度组合为一个动态标量分数，然后使用贪心搜索，每轮只保留一个候选。 LexiDT 虽然将标量目标替换为字典序目标，但仍然只保留一条搜索路径，因此提升可能有限。

新的方法暂命名为：

> **AE-PBS：Adaptive Epsilon-Constrained Pareto Beam Search**

其核心是：

1. 将“旧模型保持正确”建模为一个逐渐收紧的约束；
2. 将“使新模型错误”和“减少修改成本”作为两个优化目标；
3. 同时保留多个互不支配的候选路径；
4. 允许搜索早期暂时经过旧模型错误的区域；
5. 最终输出仍严格满足“旧模型正确、新模型错误”。

---

# 2. 研究目标

AE-PBS 主要解决 LexiDT 和 DT4LM 的两个共同问题。

## 2.1 避免单路径贪心的局部最优

原有搜索每轮执行：

[
x_{t+1}
=
\arg\max_{x'\in C(x_t)} \operatorname{score}(x').
]

一旦选择了某个词替换，其他候选路径就被永久丢弃。对于不可逆的离散文本修改，早期的一次错误选择可能导致后续再也无法找到差分输入。

AE-PBS 维护大小为 (K) 的候选前沿，同时保留：

* 更接近新模型错误边界的候选；
* 修改较少、仍有后续搜索潜力的候选；
* 暂时轻微违反旧模型正确约束的候选。

## 2.2 避免严格字典序过早剪枝

LexiDT 将旧模型正确性放在最高优先级，因此会淘汰所有暂时导致旧模型错误的候选。

但某些有效路径可能是：

[
\text{旧对、新对}
\rightarrow
\text{旧错、新对}
\rightarrow
\text{旧对、新错}.
]

AE-PBS 在搜索早期允许旧模型 margin 有限地小于 0，然后逐步收紧约束；最终结果仍必须满足旧模型正确。

# 3. DT4LM 工作流中的修改位置

## 3.1 原 DT4LM 工作流

```text
原始输入
    ↓
文本变换
    ↓
原有语义及修改约束
    ↓
查询新旧模型
    ↓
动态标量目标打分
    ↓
贪心选择一个候选
    ↓
继续修改或成功终止
```

## 3.2 AE-PBS 工作流

```text
原始输入
    ↓
文本变换
    ↓
原有语义及修改约束
    ↓
查询新旧模型
    ↓
计算旧模型 margin、新模型 margin 和修改成本
    ↓
根据当前查询预算计算 ε
    ↓
区分 ε-可行候选与不可行候选
    ↓
Pareto 非支配排序与候选前沿维护
    ↓
选择一个前沿候选进行下一次扩展
    ↓
继续搜索或严格成功终止
```

## 3.3 模块修改范围

| DT4LM 模块         | 是否修改 | AE-PBS 中的处理          |
| ---------------- | ---: | -------------------- |
| 文本变换             |    否 | 沿用 Kuleshov 的词嵌入替换   |
| 停用词约束            |    否 | 原样沿用                 |
| 重复修改约束           |    否 | 原样沿用                 |
| 最大修改比例           |    否 | 原样沿用                 |
| ThoughtVector 约束 |    否 | 原样沿用                 |
| GPT-2 流畅性约束      |    否 | 原样沿用                 |
| 差分成功条件           |    否 | 仍为旧模型正确、新模型错误        |
| 修改成本             |    否 | 沿用词级修改率              |
| 动态标量目标           |    是 | 替换为约束加双目标表示          |
| 单路径贪心搜索          |    是 | 替换为异步 Pareto beam 搜索 |
| 对抗训练             |    否 | 仍可使用生成的差分输入训练        |

因此，AE-PBS 是对 implementation plan 中 `objective` 和 `search` 两部分的替换；`kuleshov_var` 的变换与约束配置保持不变。

# 4. 核心定义

设原始输入为 (x)，真实标签为 (y)，修改后的候选为 (x')。

## 4.1 旧模型正确 margin

[
m_{\mathrm{old}}(x')
=
z_{\mathrm{old},y}(x')
-
\max_{k\ne y}z_{\mathrm{old},k}(x').
]

其中 (z) 表示分类 logits。

当：

[
m_{\mathrm{old}}(x')>0
]

时，旧模型预测正确。

## 4.2 新模型错误 margin

[
m_{\mathrm{new}}(x')
=
\max_{k\ne y}z_{\mathrm{new},k}(x')
-
z_{\mathrm{new},y}(x').
]

当：

[
m_{\mathrm{new}}(x')>0
]

时，新模型预测错误。

如果模型接口只有概率，则使用：

[
m_{\mathrm{old}}
=
\log(p_{\mathrm{old},y}+\delta)
-
\log\left(\max_{k\ne y}p_{\mathrm{old},k}+\delta\right),
]

[
m_{\mathrm{new}}
=
\log\left(\max_{k\ne y}p_{\mathrm{new},k}+\delta\right)
-
\log(p_{\mathrm{new},y}+\delta),
]

其中：

[
\delta=10^{-12}.
]

## 4.3 修改成本

沿用 DT4LM 的词级修改率：

[
c(x,x')
=
\frac{|\operatorname{modified_indices}(x')|}
{N_{\mathrm{words}}(x)}.
]

对于句子对任务，分母为两个原始句子的总词数，分子为两个字段中修改位置数之和。

# 5. 自适应 ε 约束

## 5.1 约束定义

最终要求是：

[
m_{\mathrm{old}}(x')>0.
]

搜索过程中暂时放宽为：

[
m_{\mathrm{old}}(x')\ge-\epsilon(q),
]

其中：

* (q)：当前已经使用的模型对查询数；
* (Q)：每个样本的总查询预算；
* (\epsilon(q))：当前允许的旧模型 margin 违反程度。

候选的约束违反量定义为：

[
v_\epsilon(x')
=
\max\left(0,-\epsilon(q)-m_{\mathrm{old}}(x')\right).
]

满足：

[
v_\epsilon(x')=0
]

的候选称为当前的 ε-可行候选。

## 5.2 初始 ε 的确定

不为所有样本使用同一个固定 margin，因为不同模型和样本的 logit 尺度不同。

原始输入第一次扩展得到候选集合 (C_1) 后，计算：

[
V^+
=
\left{
\max(0,-m_{\mathrm{old}}(x')):
x'\in C_1,\ m_{\mathrm{old}}(x')<0
\right}.
]

如果 (V^+) 非空，则：

[
\epsilon_0
=
Q_{0.75}(V^+),
]

即使用首轮旧模型错误候选违反量的 75% 分位数。

如果没有候选导致旧模型错误，则：

[
\epsilon_0=0.
]

该计算使用第一次扩展已经获得的模型结果，不增加额外模型查询。

## 5.3 ε 衰减

采用查询预算驱动的二次衰减：

[
\epsilon(q)
=
\epsilon_0
\left(
1-\frac{q}{Q}
\right)^2.
]

因此：

* 搜索早期允许较大的临时违反；
* 随着预算消耗，约束逐渐收紧；
* 当预算即将耗尽时：
  [
  \epsilon(q)\rightarrow0.
  ]

需要强调：ε 只影响候选保留，不改变最终成功条件。

# 6. Pareto 多目标选择

在当前 ε-可行候选中，优化两个目标：

[
\max m_{\mathrm{new}}(x'),
]

[
\min c(x,x').
]

候选 (a) 支配候选 (b)，当且仅当：

[
m_{\mathrm{new}}(a)\ge m_{\mathrm{new}}(b),
]

[
c(a)\le c(b),
]

并且至少一个不等式严格成立。

这允许同时保留两类候选：

* 修改较少，但尚未接近新模型错误边界；
* 修改较多，但已经非常接近或跨越新模型错误边界。

## 6.1 为什么旧模型 margin 不作为第三个 Pareto 目标

如果同时优化：

[
m_{\mathrm{old}},\quad m_{\mathrm{new}},\quad-c,
]

搜索可能保留旧模型 margin 极高、但对新模型几乎没有攻击效果的候选。

因此，AE-PBS 将目标划分为：

* 旧模型 margin：约束；
* 新模型 margin：主要目标；
* 修改成本：质量目标。

这比三个目标平等处理更符合差分测试的实际要求。

---

# 7. 异步 Pareto Beam Search

普通同步 beam search 每轮同时扩展所有 beam 候选。这样同一轮候选通常拥有相同的修改次数，修改成本在 Pareto 排序中几乎不起作用，而且查询数量会随 beam size 快速增长。

AE-PBS 采用**异步 beam**：

* 维护最多 (K) 个未扩展候选；
* 每次只扩展其中一个候选；
* 未被扩展的候选继续保留；
* 新生成的深层候选与浅层候选共同竞争 beam 位置。

因此，beam 中可以同时存在不同修改深度的候选，修改成本才真正成为有效目标。

## 7.1 候选状态

每个搜索状态至少保存：

```python
@dataclass
class DifferentialSearchState:
    attacked_text: AttackedText
    old_prediction: int
    new_prediction: int
    old_margin: float
    new_margin: float
    modification_cost: float
    modified_indices: frozenset[int]
    parent_id: str | None
    depth: int
    generation_order: int
    expanded: bool
```

扩展过的状态不再进入可扩展 beam，避免反复扩展同一个输入。

## 7.2 Beam 容量

首轮主配置：

[
K=5.
]

即最多保留 5 条候选路径。

敏感性实验使用：

[
K\in{1,3,5,10}.
]

其中：

* (K=1)：退化为单路径搜索；
* (K=5)：主配置；
* (K=10)：检查更宽搜索是否继续获得收益。

# 8. 候选排序与 Beam 更新

## 8.1 约束支配规则

对任意两个候选 (a,b)，按照以下顺序比较。

### 情况一：只有一个候选 ε-可行

ε-可行候选优先。

### 情况二：两者均 ε-可行

根据：

[
\left(m_{\mathrm{new}},-c\right)
]

执行 Pareto 非支配排序。

### 情况三：两者均不可行

优先选择约束违反量更小的候选：

[
v_\epsilon(a)<v_\epsilon(b).
]

如果违反量相同，再比较：

[
m_{\mathrm{new}}
]

和修改成本。

## 8.2 Beam 填充

将候选分为非支配层：

[
P_1,P_2,\ldots
]

依次将候选加入新 beam。

如果最后一个非支配层不能完整放入，则使用拥挤距离选择，优先保留目标空间中差异较大的候选。

排序稳定性规则为：

1. Pareto rank 更低；
2. 拥挤距离更大；
3. 新模型错误 margin 更大；
4. 修改成本更小；
5. 候选生成顺序更早。

## 8.3 下一扩展节点

每次只从 beam 中选择一个未扩展状态：

1. 当前 ε-可行候选优先；
2. Pareto rank 最低；
3. 拥挤距离最大；
4. 新模型 margin 更大；
5. 修改成本更小；
6. 生成顺序更早。

选中的状态从 beam 中移除并标记为已扩展，其候选子节点与剩余 beam 合并后重新排序。

# 9. 成功条件与终止

ε 只用于搜索，最终成功条件严格沿用 DT4LM：

[
\operatorname{pred}_{old}(x')=y,
]

[
\operatorname{pred}_{new}(x')\ne y.
]

若同一次扩展得到多个成功候选，按以下顺序选择：

1. 修改成本最低；
2. 新模型错误 margin 最大；
3. 旧模型正确 margin 最大；
4. 候选生成顺序更早。

即：

[
x^*
=
\arg\min_{x'\in C_{\mathrm{success}}}
\left(
c(x,x'),
-m_{\mathrm{new}}(x'),
-m_{\mathrm{old}}(x')
\right).
]

随后立即终止当前样本搜索。

如果查询预算耗尽或 beam 为空，则返回失败。

# 10. 完整伪代码

```python
frontier = [build_state(original_input)]
expanded_ids = set()
epsilon_0 = None

while frontier and query_count < query_budget:
    epsilon = compute_epsilon(
        epsilon_0=epsilon_0,
        query_count=query_count,
        query_budget=query_budget,
    )

    parent = select_expansion_state(
        frontier=frontier,
        epsilon=epsilon,
    )

    frontier.remove(parent)
    expanded_ids.add(parent.id)

    candidates = transform(parent.attacked_text)
    candidates = apply_original_kuleshov_constraints(candidates)
    candidates = deduplicate(candidates)
    candidates = remove_already_expanded(candidates, expanded_ids)
    candidates = truncate_to_remaining_budget(candidates)

    evaluated = query_old_and_new_models(candidates)

    for candidate in evaluated:
        candidate.old_margin = compute_old_margin(candidate)
        candidate.new_margin = compute_new_margin(candidate)
        candidate.modification_cost = compute_modification_cost(candidate)

    if epsilon_0 is None:
        epsilon_0 = estimate_initial_epsilon(evaluated)

    successful = [
        candidate
        for candidate in evaluated
        if candidate.old_prediction == gold_label
        and candidate.new_prediction != gold_label
    ]

    if successful:
        return select_minimum_cost_success(successful)

    epsilon = compute_epsilon(
        epsilon_0=epsilon_0,
        query_count=query_count,
        query_budget=query_budget,
    )

    frontier = pareto_frontier_select(
        candidates=frontier + evaluated,
        epsilon=epsilon,
        beam_size=beam_size,
    )

return failure
```

## 14.5 搜索诊断指标

### 非贪心路径贡献率

[
R_{\mathrm{non\text{-}top1}}
=
\frac{
#{\text{AE-PBS独有成功且首步不是动态目标top-1}}
}{
#{\text{AE-PBS成功}}
}.
]

### 临时不可行路径比例

[
R_{\mathrm{escape}}
=
\frac{
#{\text{成功路径中存在 }m_{\mathrm{old}}<0\text{ 的样本}}
}{
#{\text{AE-PBS成功}}
}.
]

### Beam 有效宽度

每轮统计：

* frontier 实际大小；
* 不同修改位置集合的数量；
* Pareto 第一前沿大小；
* 不同修改深度数量。

如果 frontier 中的候选长期完全相同，说明 beam 没有产生真实的路径多样性。

# 18. 成功标准

AE-PBS 进入后续扩展实验，建议至少满足以下一项：

1. 在相同查询预算下，GSR 相对 DT4LM-Dynamic 提高至少 3 个百分点，且 AMR 相对增幅不超过 10%；
2. GSR 基本相同，但 Success@500 或 QPS 改善至少 10%；
3. 在两个数据集上都增加独有成功样本，并且新增成功中至少 20% 来自非 top-1 路径或临时不可行路径。

如果 Dynamic-Beam 与 AE-PBS 表现接近，则主要收益来自多路径搜索，而不能将收益归因于 Pareto 和 ε 约束。

如果所有 beam 方法都没有明显优于单路径方法，则瓶颈更可能位于词级候选空间，而不是目标函数或搜索策略，此时不应继续增加多目标优化复杂度。

## 最终概括

AE-PBS 对 DT4LM 做了两项实质性修改：

> **目标层面**：将旧模型正确性从加权目标改为逐步收紧的约束，将新模型错误 margin 与修改成本作为 Pareto 双目标。

> **搜索层面**：将单路径贪心改为异步的有界 Pareto frontier，使多个不同深度、不同目标折中的路径能够继续搜索。

它的目标不是让某个标量分数更加精巧，而是扩大搜索能够到达的有效区域，并在固定查询预算下发现原贪心搜索遗漏的差分输入。
